# camt053-writer-xlsx v0.0.23

## Highlights ⭐️

* **Statements with control characters export**: a control character in statement text, which SWIFT MT940 narrative can carry, used to abort the whole workbook with `IllegalCharacterError`. It is now written as U+FFFD, and the sheets and columns are unchanged.
* **In lockstep with camt053 0.0.23**: the suite's six packages are back on one version, this package requires `camt053` 0.0.23 or newer (the first core that keeps advised fastapi, starlette and cryptography releases from resolving), and the daily suite check now compares this tree with this package's own release.
* **Verifiable releases**: every CI and release action is pinned by commit, tools install from hash-pinned files audited with `pip-audit`, and each release carries a CycloneDX SBOM, SLSA provenance and sigstore signatures.
* **Documented to the family standard**: a user manual with every column, a rendered demo, REUSE licensing on every file, and a check that every place the version is written agrees.
