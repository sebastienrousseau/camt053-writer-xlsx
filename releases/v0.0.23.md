# camt053-writer-xlsx v0.0.23

## Highlights ⭐️

* **Same workbook, same columns**: `write_xlsx` writes exactly what it wrote in 0.0.20 for the same document, so macros and pivot tables built on the four sheets keep working.
* **In lockstep with camt053 0.0.23**: the suite's six packages are back on one version, this package requires `camt053` 0.0.20 or newer, and the daily suite check now compares this tree with this package's own release.
* **Verifiable releases**: every CI and release action is pinned by commit, tools install from hash-pinned files audited with `pip-audit`, and each release carries a CycloneDX SBOM, SLSA provenance and sigstore signatures.
* **Documented to the family standard**: a user manual with every column, a rendered demo, REUSE licensing on every file, and a check that every place the version is written agrees.
