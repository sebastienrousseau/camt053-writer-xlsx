# camt053-writer-xlsx v0.0.26

## Highlights ⭐️

* **In lockstep with camt053 0.0.26**: this package requires `camt053` 0.0.26 or newer, below 1, so every member of the suite ships and resolves the same version.
* **A smaller install**: camt053 0.0.26 keeps its REST stack behind `camt053[api]`, so installing this writer no longer brings fastapi, uvicorn or the packages they need. `write_xlsx` writes the same four sheets, columns and cell values for the same document as 0.0.25.
